# American Gladiators Ultimate Edition — design contract

- Standalone Windows game; Genesis-inspired 16-bit pixel art with authentic television arena references.
- Retro mode draws exclusively on the original 1989–1996 run. Modern mode uses the 2026 Amazon revival. No 2008 content.
- Contender Season Mode is available from the beginning. Gladiator Mode and Create a Gladiator are both locked until winning Season Mode once; the unlock persists across runs and modes.
- AI controls all Gladiators in normal Contender play. Gladiator Mode reverses the role.
- Retro event roster includes Assault and Retro Eliminator. Modern event roster includes The Edge, The Ring, Destruction, Crash Course and Eliminator '26. Powerball and Atlasphere are required in both eras. Other shared events must be checked against broadcast appearance, not assumed.
- Custom mode may mix event eras, Gladiators, and either Eliminator.
- The Eliminator is always the LAST event; no normal events may follow it.
- Modern show structure: three scored events, then Eliminator '26.
- Classic original theme and trumpet fanfare used across both eras. Licensed recordings are not bundled; implement local audio imports.
- Event start sequence: fanfare, introduction, 'Contender(s) ready! Gladiator(s) ready!', then whistle (Retro) or '3, 2, 1' and whistle (Modern).
- Creator design inspired by the Chase contestant/Chaser creator; full season-accurate rosters including original short-lived and alternate Gladiators.
- Windows USB and Bluetooth controller support, Xbox/PlayStation equivalent layouts, remapping, keyboard fallback.
- All event visual layouts and rules must be researched and recreated in 16-bit form.
- This initial scaffold is NOT a full game. Powerball is a simplified mechanics demonstration, and other events are placeholders; completion of the prototype season is not yet a legitimate championship.
